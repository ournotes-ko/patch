# 뱅드림! 아워 노트 한글 패치 (일본판용)

일본판 「バンドリ！ アワーノーツ」(com.bushiroad.sirius)를 글로벌판의 **공식 한국어 데이터**로 한글화하는 비공식 패치입니다. 기계번역은 쓰지 않습니다. 일본 계정과 일본 서버를 그대로 씁니다.

> **주의.** 게임사와 관계없는 비공식 패치입니다. 수정된 게임 앱을 쓰므로 게임 이용 약관에 어긋날 수 있고, 계정 제재 등 모든 결과는 사용자 책임입니다. 게임과 번역 데이터의 권리는 각 권리자에게 있습니다.

## 받기
- **패치 앱** `OurNotesPatcher.apk`: 이 저장소의 [Releases](../../releases/latest). 번역 맵·이미지 데이터는 패치 앱이 [patch-data](https://github.com/ournotes-ko/patch-data)에서 받습니다.
- **게임 APK** (패치판): 최신 릴리스 본문의 다운로드 링크(패치 앱 업데이트 카드의 `다운로드`로도 열 수 있음)
- 받은 파일은 [SHA256SUMS.txt](https://github.com/ournotes-ko/patch-data/blob/main/SHA256SUMS.txt)의 sha256과 같은지 확인하세요. 패치 앱은 받을 때 직접 확인합니다.

## 준비물
- Android 9 이상 기기(arm64), 루트 불필요
- [Shizuku](https://shizuku.rikka.app/) — 무선 디버깅 또는 PC의 adb로 시작

## 꼭 먼저 할 일 — 계정 연동
공식판(Play 스토어판)이 설치되어 있으면 서명이 달라 **덮어쓸 수 없습니다.** 공식판을 지우면 기기의 게임 데이터가 사라지므로, 지우기 전에 게임 안에서 **Bushiroad ID 연동**을 반드시 해 두세요. 연동해 두면 패치판 설치 후 같은 계정으로 이어서 할 수 있습니다.
이미 이 패치의 이전 판을 쓰고 있다면 지우지 말고 그대로 덮어 설치하면 됩니다(데이터 유지).

## 설치 순서
1. Shizuku를 실행하고 "시작"을 눌러 실행 중 상태로 만듭니다.
2. `OurNotesPatcher.apk`를 설치하고 실행합니다. 상태 카드 Shizuku 줄의 `권한 요청`을 누르고 Shizuku 권한 창에서 **허용**을 누릅니다. Shizuku를 패치 앱보다 나중에 켰다면 같은 줄의 `재시작`을 누릅니다.
3. 게임 APK를 받은 뒤, 패치 탭 단계 1 `게임 설치`의 `설치`에서 받은 파일을 고릅니다.
4. 게임을 한 번 실행해 타이틀 화면까지 들어가고 추가 데이터 다운로드(Wi-Fi 권장)를 마칩니다. 게임은 단계 카드 아래 `게임 실행`으로도 띄울 수 있습니다.
5. 단계 2 `패치 적용`의 `적용`을 누르고(번역 맵 적용 → 이미지 교체) `게임 다시 시작`을 누릅니다.
6. 게임을 다시 시작하면 한국어로 표시됩니다.

## 업데이트
패치 앱은 열 때와 열어 둔 동안 1시간마다 새 판을 확인합니다(1.29). 새것이 있으면 패치 탭 맨 위에 `업데이트 있음 N개` 카드가 나오고 패치 탭 아이콘에 배지가 붙습니다. 카드를 누르면 펼쳐집니다.
- **패치 앱·번역 맵·이미지 데이터:** `업데이트`를 누르면 받아서 확인한 뒤 바로 설치·적용합니다. 패치 앱은 설치가 끝나면 앱이 닫히니 다시 여세요.
- **게임 APK:** `다운로드`를 누르면 받을 곳을 고르는 창이 뜨고, 고른 곳이 브라우저로 열립니다. 받은 파일을 단계 1 `설치`에서 고르면, 앱이 배포 파일과 같은지 확인한 뒤 설치합니다.
- 확인이 실패하면 같은 카드에 이유와 `다시 시도`가 나옵니다. 제목 오른쪽 새로고침 아이콘으로도 다시 확인할 수 있습니다.
- **알림(1.30부터):** 앱이 꺼져 있어도 새 판이 나오면 기기 알림으로 알려 줍니다. 첫 패치를 마치면 `업데이트 알림을 받을까요?` 창이 뜹니다. `알림 받기`를 누른 뒤 권한 창에서 **허용**을 누르세요. `나중에`를 눌렀거나 거부했다면 설정 탭 `알림`에서 켤 수 있고, `급한 업데이트만 받기`도 고를 수 있습니다. 알림을 누르면 업데이트 카드가 펼쳐진 채로 열립니다. 급한 업데이트(예: 서버 갱신으로 이미지가 일본어로 돌아갔을 때)는 `급한 업데이트`로 표시합니다.
  - 즉시 알림은 Firebase 클라우드 메시징(구글 플레이 서비스 필요)을 씁니다. 개인 정보는 보내지 않고 분석 기능도 쓰지 않지만, Firebase가 알림을 전하기 위해 기기별 설치 ID를 만듭니다.
  - 즉시 알림을 못 받는 기기(구글 플레이 서비스 없음, 백그라운드 제한)도 12시간마다의 확인과 앱을 열 때의 확인으로 알게 됩니다.
  - **강제 중지하면 알림이 멈춥니다.** 설정 > 앱에서 패치 앱을 `강제 중지`하면, 안드로이드가 다시 열 때까지 즉시 알림과 12시간 확인을 모두 막습니다. 패치 앱을 한 번 열면 다시 받습니다. 최근 앱 목록에서 쓸어 닫는 것은 괜찮습니다.
- GitHub 계정이 있으면 이 저장소 오른쪽 위 **Watch → Custom → Releases**를 켜서 새 릴리스를 메일로도 받을 수 있습니다.

## 되돌리기
- 패치 전체 제거: 계정 연동 확인 후 게임 삭제 → 공식판 설치.

## 일본어로 남는 것
- 선물 메시지 등 서버가 보내는 문장, 한국 서버에 같은 공지가 없는 공지(같은 공지가 있으면 게임 v105z19 + 패치 앱 1.33부터 한국 서버 공식 문장), 글로벌판에 아직 없는 일본판 전용 스토리·이벤트 대사
- 글로벌판에도 한국어 그림이 없는 이미지(예: CD 구매 특전 스티커 교환소 배너, `9.24世界同時リリース!` 배너)
- 글로벌판도 원어를 쓰는 곡명·인명
- 글로벌판과 이미지 비율이 달라 무손실 교체가 안 되는 스토리 이벤트 아이콘 2개

## 자주 묻는 질문
- **게임에서 Google 연동을 누르면 '연동에 실패했습니다'가 나와요.** 패치판은 서명이 공식판과 달라서 Google(Play 게임즈) 로그인을 쓸 수 없습니다. 계정 연동과 이전은 **Bushiroad ID**로 하세요. Google로만 연동한 계정이라면, 공식판을 지우기 전에 공식판에서 Bushiroad ID 연동을 추가해 두어야 합니다.
- **일부 글자가 잠깐 일본어였다가 바뀌어요.** 실행 직후 몇 초 동안은 번역이 걸리기 전 화면이 보일 수 있습니다. 다른 화면에 다녀오면 한국어로 바뀝니다.
- **드물게 실행 후 1분 안쪽에서 게임이 꺼져요.** 다시 실행하면 되고, 계정·진행 데이터에는 영향이 없습니다.
- **게임이 업데이트를 요구해요.** 일본판이 새 버전으로 올라가면 이 패치는 맞지 않습니다. 새 버전용 패치를 기다려 주세요.
